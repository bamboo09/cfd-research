# CFD 科研 Skill 的对照试验与基准回放

2026-11-18。两道题各用两个独立 Agent 执行一次。合成题两组均为 12/12，公开 SU2 题为通用 Agent 5/6、加载 Skill 的 Agent 6/6。两组均正确完成局部编辑和定量比较。唯一得分差异是 SU2 题中加载 Skill 的报告额外追到了缺失的重启解。另有三次单因素后处理消融，以及一个 DFG 公开时序的独立回放。

## 一、加载 Skill 是否改变了 Agent 的表现

每次使用新 Agent，上下文不继承设计过程。成对的两个工作目录初始输入相同，任务、工具和禁止联网的限制相同；处理组额外收到 Skill 及其脚本的路径。评分项在运行前写好，评审者能看到分组。各条件各题只有一次，未固定采样随机种子或测量 token/耗时；这里得到的是案例级结果。说明文字和辅助脚本作为一个整体引入，无法分配各自贡献。

| 任务 | 预设判据 | 通用 Agent | 加载 Skill | 可独立检查的产物 |
|---|---|---:|---:|---|
| C7，教学用论文节选、配置和历史数据 | 跨文件物性与壁面 1–3、Re 与修改影响 4–6、复现缺项 7、力系数及归因 8–12 | 12/12 | 12/12 | [原始输入](paired/input) · [任务](paired/task.txt) · [评分项](paired/rubric.md) · [通用报告](paired/outputs/baseline.md) · [Skill 报告](paired/outputs/with-skill.md) · [两组相同的补丁](paired/outputs/input-change.patch) |
| SU2 v8.3.0 公开 Poiseuille 配置、网格及入口文件 | 驱动方式、边界与修改、两类流量、重启证据共六项 | 5/6，缺第 6 项的重启定位 | 6/6 | [输入重建脚本](su2/prepare.py) · [任务](su2/task.txt) · [评分项](su2/rubric.md) · [通用报告](su2/outputs/baseline.md) · [Skill 报告](su2/outputs/with-skill.md) · [两组相同的补丁](su2/outputs/input-change.patch) |

**C7。** 两组都沿 include 找到算例 ν 是论文值的十倍，并定位到上壁误用滑移条件。除授权的入口标量，两份最终输入均与原始输入逐字节一致。两组均算出 A、B 时间平均力为 0.170、0.300 mN，且都指出历史运行没有配置快照。C7 没有显示 Skill 在该通用 Agent 上有额外得分。

**SU2。** 试验采用 v8.3.0 固定标签的两份官方配置、51 点剖面、原网格及同版模板节选。两组都对有效的入口文件作了修改；独立复核了所有 51 点、其余列和其余文件，49 个非零速度值改变。单位展长体积流量从 0.9996 变为 1.2495 m²/s；密度为 1 kg/m³ 时，相应质量流量为 0.9996 与 1.2495 kg/(m·s)。两组都限定了稳态推断。Skill 报告还指明 RESTART_SOL=YES 且副本缺少 SOLUTION_FILENAME 所指的 solution_flow_profile；这一分来自输入可追溯性，与速度或流量的计算正确率无关。[SU2 官方配置](https://github.com/su2code/SU2/tree/v8.3.0/TestCases/navierstokes/poiseuille) · [网格与剖面来源](https://github.com/su2code/TestCases/tree/v8.3.0/navierstokes/poiseuille)

复做 Agent 对照时，将 C7 的 input 复制到两个新目录、各复制一份 task.txt；SU2 可用下方 prepare 命令为两组各生成一份目录。向独立 Agent 提供各自目录与同一任务，处理组另给 Skill。保留每次的报告与实际输入差异，按相应 rubric 计分。两组均允许使用通用 Python 和 shell。

## 二、单独移除一个后处理条件会发生什么

固定 C7 的原始力数据，每次只替换一个计算条件。完整定义取 [1, 4] s，分段线性插值，做梯形积分后除以时长；两组均以 0.020 m/s 的基线速度归一化。以下列的是无量纲力系数，差值为 B−A。

| 计算条件 | A | B | B−A |
|---|---:|---:|---:|
| 完整定义 | 0.8500 | 1.5000 | +0.6500 |
| 移除共同窗口，各取自己的整个时序 | 3.1500 | 1.7944 | −1.3556 |
| 移除时间权重，对窗口内采样及插值端点等权 | 0.8000 | 1.3400 | +0.5400 |
| 移除共同参考速度，各用本工况动压 | 0.8500 | 0.6667 | −0.1833 |

在这组有意包含启动段和不等间距输出的教学数据中，窗口与归一化各自都足以翻转排序。各用本工况动压也可以定义一个有意义的系数，但与题中图 3 的指标不同。这组试验测的是计算定义改变的后果，无法估计真实项目犯错的概率。[可执行消融](paired/operators.py) · [原始数值结果](paired/outputs/operators.json)

## 三、公开基准能否从作者数据重算

选定 DFG 2D-2，复核作者发布页“Exemplary Results”中 Level 6、名义时间步 1/200 的旧版 Q₂ 力数据。网页另列了采用高阶力积分的新版；本次只将旧表与配套旧时序进行对照。[基准页与表格](https://wwwold.mathematik.tu-dortmund.de/~featflow/en/benchmarks/cfdbenchmarking/flow/dfg_benchmark2_re100.html)

| 复现条件 | 从哪里得到 | 算例或验收如何落实 |
|---|---|---|
| 域长 2.2、高 0.41；圆心 (0.2, 0.2)，直径 0.1；ν=0.001，ρ=1 | 基准页 Geometry、Boundary conditions、Reynolds number | 抛物线入口峰值 1.5，导出均速 1.0 和 Re=100。上下壁及圆柱无滑移；出口按给定牵引条件实现，移植到其他求解器要核对等价形式 |
| 空间 Q₂/不连续 P₁、Crank–Nicolson、网格级与名义步长 | 基准页 Reference configuration 和目标表行 | 保持网格族、离散与力积分版本对应；只移植部分方法时，标出替代条件 |
| CD、CL 两极值的中点；St=D/(Umean T) | 基准页 Important numerical quantities、Setup | 在连续两个 CL 谷值间统计。作者作图脚本把该文件时间减去 8.535625 s；档内时间按原始第二列读取 |
| 偏差与容差 | 参考表给出显示精度，本次没有约定通过容差 | 保留带符号偏差。数据回放不能独立确认原始网格、瞬态发展历史与求解器收敛 |

从原始 ZIP 的 bdforces_q2_lv6_dt3 取作者指定相位起点，再搜索下一个采样升力谷值。端点为 [8.535625, 8.866875] s，含 266 行，T=0.331250 s。作者计算名义步长和档内相邻输出间隔是两个量，积分直接使用时序列。[作者原始 ZIP](https://wwwold.mathematik.tu-dortmund.de/~featflow/media/dfg_bench2_2d/draglift_q2_cn_lv3-6_dt1-4.zip) · [作者绘图脚本](https://wwwold.mathematik.tu-dortmund.de/~featflow/media/dfg_bench2_2d/plot_bench2.plt) · [周期摘录](dfg/cycle.csv)

| 无量纲指标 | 公开表值 | 本次重算 | 重算减表值 |
|---|---:|---:|---:|
| CD 极值中点 | 3.1884 | 3.18854047 | +0.00014047 |
| CL 极值中点 | −0.0173 | −0.01733664 | −0.00003664 |
| St | 0.30188 | 0.30188679 | +0.00000679 |

同一周期的 CL 物理时间均值是 −0.01782826。即使输入完全相同，采用时间均值也会改变比较结果。CD 的偏差大于参考表最后一位的半个单位，来源材料未能确定差异的具体原因，故保留原偏差。以上是公开数据后处理回放；本机未启动 CFD 求解器，也没有重新生成该流场。[回放代码](dfg/replay.py) · [完整精度与 SHA-256](dfg/results.json)

## 复算命令

在项目根目录运行，数值脚本使用 Python 3.9+ 标准库；SU2 输入重建另需 curl 和联网。另存输出时可直接与随附 JSON 比对。

```sh
python3 evaluations/paired/operators.py
python3 evaluations/dfg/replay.py
python3 evaluations/su2/prepare.py /tmp/su2-cfd-new-copy
```

如需从上游验证周期摘录，下载上文 DFG 原始 ZIP 后运行下列命令。脚本先验证整个 ZIP 的 SHA-256，再从指定成员重新提取 cycle.csv。

```sh
python3 evaluations/dfg/replay.py --archive /path/to/draglift_q2_cn_lv3-6_dt1-4.zip
```
