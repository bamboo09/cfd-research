# 面向 CFD 科研 Agent 的四项工作流调研

调研于 2026-11-18 完成。问题是：Agent 交来的算例、一次局部编辑、一套论文复现方案或一张对比图，研究人员能拿什么证据判断它是否适用？检索覆盖 CFD Agent、开源求解器及回归库、论文复现、验证与确认（V&V）、后处理和采样不确定度。优先使用作者论文、作者仓库、求解器官方文档和原始基准。以下为定向调研；没有按系统综述协议筛选所有论文。最后两节区分本地实测与从文献推导的工作方法。

## 现有科研 Agent 交付了什么

| 项目或论文 | 已有能力与评测对象 | 对本项目的设计影响 |
|---|---|---|
| MetaOpenFOAM | 由自然语言组织网格、求解和后处理。仓库说明默认检索嵌入实现与原论文设置可能不同。 | 复现时记录实际实现版本和依赖；即使代码公开，默认运行路径也可能变化。[论文](https://arxiv.org/abs/2407.21320) · [作者仓库](https://github.com/Terry-cyx/MetaOpenFOAM) |
| Foam-Agent / FoamBench | 跨文件依赖感知的生成、按环节检索，以及覆盖不同任务的执行评测。 | 从“生成哪些文件”延伸出“同一设置经过哪些文件才真正生效”。把执行完成、研究约束满足、目标量正确分别记录。[论文](https://arxiv.org/abs/2505.04997) · [工作流研究](https://arxiv.org/abs/2509.18178) · [作者仓库](https://github.com/csml-rpi/Foam-Agent) |
| A Preliminary Assessment of Coding Agents for CFD Workflows | 在教程衍生任务与二维障碍物流动任务上评估通用编程 Agent；教程复用、日志反馈和模型能力影响执行表现。 | 保留“通用 Agent + 相同工具”这个有竞争力的对照。简单任务出现平局也有信息量。[论文与任务分组](https://arxiv.org/html/2602.11689v1) |
| EasyFoam / ExtFoamBench | 作者将技能组织与执行完成、数值可靠性、目标量符合度的分项评测结合。 | 科研技能已有近似工作。这里具体实现受控编辑、文献来源记录、原始数据回放，并对这些交付物逐项评分。[作者预印本](https://arxiv.org/abs/2611.14525) |

这些研究使用不同版本、模型、工具预算、任务和成功条件。横向成功率不能直接回答“只改入口速度是否破坏对照”或“论文的力系数是否算对”。本项目选择可在已有求解器上使用的一个 Skill，四个入口共用运行身份、来源和指标定义，可在一次请求中连续使用；无需部署单独的 Agent 服务。

## 四项设计各自解决哪个科研判断

### 1. 配置审查先找到生效输入，再判断物理条件

OpenFOAM 字典支持引用、变量与量纲表达，同一个数值有时代表运动学压力，有时代表 Pa。应从启动目录和所解方程追到有效值，随后检查 patch、物性与参考尺度能否同时满足研究意图。可运行的最小示例也可能包含不适用于本工况的默认值。[Foundation v13 文件、宏与量纲](https://doc.cfd.direct/openfoam/user-guide-v13/basic-file-format) · [OpenFOAM-13 源码与教程](https://github.com/OpenFOAM/OpenFOAM-13)

NASA 的验证指南把迭代、守恒、空间和时间收敛分别检查。Turbulence Modeling Resource 的零压梯度平板提供同族网格，还专门说明 Re 所用长度和低 Mach 可压缩设置。配置审查据此把“模型、参考尺度与边界已核对”和“网格足以支持这一目标量”拆成不同的结论，后者须有数值证据。[NASA 验证流程](https://www.grc.nasa.gov/www/wind/valid/tutorial/verassess.html) · [TMR 平板](https://tmbwg.github.io/turbmodels/flatplate.html) · [TMR 数据仓库](https://github.com/TMBWG/turbmodels)

### 2. 受控修改要核对实际控制量与整套输入

SU2 的两个 Poiseuille 回归算例共用网格，但一个通过体力和周期边界驱动，另一个从外部文件读取入口剖面。自由来流、边界标记中的标量、逐点剖面可能同时存在。对后者，指定的修改应落到剖面幅值；对前者，把“入口改大”翻译成增加体力会改变研究问题。这两份配置和配套网格已在本地逐项核对。[周期配置](https://github.com/su2code/SU2/blob/v8.3.0/TestCases/navierstokes/poiseuille/lam_poiseuille.cfg) · [剖面配置](https://github.com/su2code/SU2/blob/v8.3.0/TestCases/navierstokes/poiseuille/profile_poiseuille.cfg) · [配套输入](https://github.com/su2code/TestCases/tree/v8.3.0/navierstokes/poiseuille)

signac 的 state point 将一组工况参数关联到独立 job 目录。沿用这个思想，Skill 对已有工程记录“基线输入、授权差异、新运行、历史结果”的对应关系；对内容做摘要、对已改文件看行级差异。SU2 对应回归脚本在指定迭代读取目标量，适合检测程序行为漂移；研究级对照还需独立的收敛和误差判据。[signac 数据模型](https://signac.readthedocs.io/en/latest/intro.html) · [SU2 v8.3.0 回归代码](https://github.com/su2code/SU2/blob/v8.3.0/TestCases/serial_regression.py) · [SU2 测例说明](https://github.com/su2code/TestCases)

### 3. 论文复现以图表及其测量定义为单位

Mesnard 与 Barba 复现自己发表的钝体流动研究，分别使用多个代码，报告了跨实现重复得到结果的实际困难。PetIBM 提供了可检查的求解实现。这给复现台账中的两列提供了理由：论文明确陈述了什么，当前版本的代码实际实现了什么；两列出现差异时，两种来源都保留。[作者论文](https://arxiv.org/abs/1605.04339) · [PetIBM 仓库](https://github.com/barbagroup/PetIBM)

Schäfer–Turek 圆柱问题包含多个工况。公开的 2D-2 定义用平均入口速度和圆柱直径算 Re，用相邻升力谷值确定周期。该页还并列提供早期力积分和后来更高阶积分的数据。复现时即使 Re 相同，变体、参考速度、采样周期、表行或积分版本混用，都会产生不同的对照对象。本项目直接读了发布页、绘图命令和时序，结果见试验报告。[原始论文](https://kent-and.github.io/mek4250/2021/SchaeferTurek1996.pdf) · [2D-2 发布页](https://wwwold.mathematik.tu-dortmund.de/~featflow/en/benchmarks/cfdbenchmarking/flow/dfg_benchmark2_re100.html) · [作者绘图命令](https://wwwold.mathematik.tu-dortmund.de/~featflow/media/dfg_bench2_2d/plot_bench2.plt)

### 4. 后处理先约定量的定义，再提取和比较

ParaView 5.11 的 TemporalStatistics 在时间上等权处理各输出步。在自适应步长或不规则输出下，样本均值与物理时间均值会不同。PyVista 的线采样提供可指定的路径与分辨率；改变采样点或插值也可能改变对比结果。Skill 要求把表面/探针、时间窗、插值、权重与原始字段随输出记录，并附带对标量 CSV 可直接执行的积分工具。[ParaView 时间统计](https://www.paraview.org/paraview-docs/v5.11.0/python/paraview.simple.TemporalStatistics.html) · [PyVista 线采样](https://docs.pyvista.org/api/core/_autosummary/pyvista.datasetfilters.sample_over_line)

Celik 等讨论离散误差的估算与报告；Oliver 等在 DNS 统计量中分析了采样相关性与离散误差的共同影响。网格加密并不能自动消除有限观测时长的影响。因而复现及后处理报告应区分发布参考值、离散误差、采样误差和实验不确定度，必要时报告缺少哪类证据。[Celik 等](https://doi.org/10.1115/1.2960953) · [Oliver 等](https://arxiv.org/abs/1311.0828) · [NASA 网格收敛指南](https://www.grc.nasa.gov/www/wind/valid/tutorial/spatconv.html) · [NASA 实验确认指南](https://www.grc.nasa.gov/www/wind/valid/tutorial/valassess.html)

## 证据覆盖

本地实测涉及合成通道算例的跨文件检查、SU2 官方配置与剖面的受控编辑，以及 DFG 已发布数据的周期统计。Agent 系统论文和仓库用于比较设计，未在本机重新部署这些框架。求解器运行、三维湍流、热耦合、多相流和实验不确定度估计未进入本次试验。各组输入、判据、原始报告及可重算命令见[消融与公开基准报告](../evaluations/结果.md)。
