# 后处理与比较

1. 绑定 run → 配置/网格版本 → 原始文件与列/场 → 提取操作 → 指标 → 图表。确认重启是否覆盖时间、并行分区是否齐全、时间为物理时间/迭代/无量纲时间。旧结果不能自动归属于刚编辑的配置。
2. 为每个指标写测量定义。力系数举例：CD=F·eD/(0.5 ρref Uref² Aref)，明确是物体受力还是流体受力、总力或仅压力项、2D 的单位展长、参考系与基准面积。分别检查每个工况使用的参考值是否符合研究设计。压差须统一测点顺序、参考压力与单位。已归一化数据再次换算需要原始标度。
3. 场数据优先调用已有函数对象、求解器原生读器、pvpython 或 PyVista。线剖面记录端点、坐标系、点数和插值；面通量记录法向、区域及积分权重；场平均区分点、单元、体积或质量加权。跨网格比较时选公共几何或可复算的映射，检查无效采样点以及并行拼接重复值。保留命令、读器版本及输出表。[PyVista 线采样](https://docs.pyvista.org/api/core/_autosummary/pyvista.datasetfilters.sample_over_line)
4. 先确定启动段、稳态/周期性与共同窗口。窗口端点落在输出点之间时，说明插值假设；禁止无依据的外推。时间均值在不等步长时按物理时间积分，样本均值、极值中点、逐周期相位平均各有不同定义。峰值受采样分辨率影响；频谱注明输出频率、采样间隔与处理方法。ParaView 的 TemporalStatistics 忽略时间间距。[ParaView 5.11 文档](https://www.paraview.org/paraview-docs/v5.11.0/python/paraview.simple.TemporalStatistics.html)
5. 一般时序 CSV 可运行 scripts/window_stats.py。显式传入数值列名（包含量纲或另行注明）及有限窗口；程序按分段线性插值处理端点，返回物理时间均值、采样极值中点和峰峰值。检查数据是否存在跨越重启/丢帧的长空档；工具报告最大积分间隔，能否插值由数据采集约定决定。使用其他统计量时写出方法并实际执行。
6. 报告原始值、差值和有意义时的相对差，与采样/离散/实验不确定度分别对照。相关时间序列的置信区间要考虑自相关或分块平均；未知的不确定度保持未知。区分观测、对假设的支持程度和机制解释，说明可能混杂的配置。数值量没有支撑时，图像只支持限定性的形态描述。

```sh
python3 "$SKILL_DIR/scripts/window_stats.py" forces.csv --time t_s --value Fx_N --window 1 4
```

每张图/表标 run、指标及单位，附数据路径、提取脚本/命令、窗口与所用归一化。不同工况的时间原点或单位未能对齐时，先交付各自能成立的指标及比较缺口。
