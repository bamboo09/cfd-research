# 配置审查

从“研究对象、控制量、响应量、需要保持的约束”反推必查项。例如给定 Re 应能在同一套速度/长度定义下由实际物性重算。下面各项按物理模型取用。

| 检查对象 | 到哪里核对 | 形成判断的方法 |
|---|---|---|
| 生效输入 | 启动命令、脚本、运行目录、求解器发行分支与版本、区域、初始/重启时刻、覆盖文件 | 从读入端追到定义端。区分 0 与 latestTime、模板与展开文件、命令行覆盖。外部引用读不到时记录引用链和未决量 |
| 物性与相似参数 | 几何缩放、物性表、场量纲、参考值 | 对照 μ=ρν，核对 Pa 与 p/ρ、绝对压/表压、温度及参考态。算 Re=UL/ν，写清速度是峰值或截面均值、长度是直径/半高/全高；可压缩流按需核对 Mach 和热力学闭合 |
| 初始值与边界 | 网格 patch/marker 清单 × 所解场的条件；初值来源 | 核对漏配和分组展开、方向/符号、静壁/动壁、滑移、周期配对、入口剖面及回流；根据方程和压力零空间判断参考压、边界是否适定。量纲不同的零值也注明物理含义 |
| 网格与模型 | 实际网格、质量报告、模型配置 | 核对尺度、拓扑、区域连接、二维假设、边界层分辨率；按所用壁面处理判断 y⁺。单元数或一个质量指标不足以认定网格独立 |
| 离散与时间推进 | 格式、耦合、线性求解器、步长与输出间隔 | 核对稳/瞬态与目标量、数值扩散/有界性、精度与稳定性限制。Co 取当地速度、步长和网格尺度，入口估算须标为尺度估算。残差判据还要结合目标量与质量平衡 |
| 实际运行表现 | 日志、通量、力/压降历史、网格和步长研究 | 记录是否收敛、瞬态是否洗脱、守恒误差分母/时间段。非稳态控制体同时考虑储存项；可压缩流检查质量通量。需要多网格/多步长证据时标明缺口 |

**OpenFOAM** 枚举有效区域的 U、p 或 p_rgh、物性、湍流设置、polyMesh/boundary、fvSchemes、fvSolution、controlDict 及其 include。先区分 Foundation 与 OpenCFD 版本及解算模块，用该版 foamDictionary 的读值功能定位有效键；在可信且完整的算例副本上，可用 checkMesh 检查实际网格，保留日志。字典可能包含动态指令，静态查看时记录未解析项。运动学压力乘密度得到动力压力需要相应的密度假设；p_rgh 还需按该求解器补回静水项。[Foundation v13 字典与量纲](https://doc.cfd.direct/openfoam/user-guide-v13/basic-file-format)

**SU2** 沿实际启动的 cfg、网格 MARKER_TAG、求解器/数学问题、量纲化方式、参考长度/面积、输出列、重启与多区域配置逐项匹配。比较同一版配置模板；regression 的目标迭代数可能远低于统计收敛所需迭代数。[SU2 回归方法](https://su2code.github.io/docs_v7/Running-Regression-Tests/)

报告中每行写“对象 | 已核查/冲突/缺证据/需专业判断 | 定位与数值 | 对目标量的影响”。将会改变问题定义的冲突排在前面；给物理建议时注明依据或要补测的量。
